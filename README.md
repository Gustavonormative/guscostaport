# Gustavo Costa — Portfólio com CMS

## Estrutura
- `index.html`: site público.
- `content/content.json`: conteúdo editável.
- `admin/`: painel Decap CMS.
- `images/`: imagens dos cases.
- `portfolio_gustavo_costa_brutalista_original.html`: backup do HTML original.

## Publicação
1. Crie um repositório público no GitHub.
2. Suba todos estes arquivos na branch `main`.
3. No Decap Turbo, conecte o GitHub, crie um site para esse repositório e copie o Site ID para `admin/config.yml`.
4. Troque `SEU_USUARIO/SEU_REPOSITORIO` pelo nome real do repositório.
5. No GitHub: Settings > Pages > Deploy from a branch > `main` > `/ (root)` > Save.
6. Depois de publicado, abra `https://SEU_USUARIO.github.io/SEU_REPOSITORIO/admin/`.
7. Entre no Decap Turbo e edite o conteúdo.

O CMS grava as alterações no repositório. O GitHub Pages publica as mudanças quando a branch configurada recebe os commits.
